# BTB

Single-vendor food ordering and delivery platform for BTB.

| App | Path | Stack |
| --- | --- | --- |
| API | `apps/api` | Node.js, GraphQL, MongoDB |
| Admin panel | `apps/admin` | Next.js |
| Customer website | `apps/web` | Next.js |
| Customer app (BTB) | `apps/app` | React Native / Expo |
| Store app (BTB-Store) | `apps/store` | React Native / Expo |
| Rider app (BTB-Rider) | `apps/rider` | React Native / Expo |

Dependencies are installed with `pnpm install` at the repo root. See each app's own README for details.
